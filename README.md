# 试映排期台

由胶片分镜条核对台扩展而来的纯前端本地应用：预置三名放映员、两个影厅和六个片段，用来安排试映场次。

- 排片时选片段、影厅、放映员与连续时段（结束时间按片段时长自动计算），加入待存批次后整批保存。
- 同一放映员或影厅时段冲突、片段未修复、或影厅当日总时长超过厅容量时，整批不保存，原排期不动。
- 修改片段的修复状态或时长后，相关未来场次自动退回待排，已完成场次保留。
- 排期表、统计与提醒实时同步，数据存 localStorage，刷新保留。

代码拆成三个业务文件：`rules.js`（排期规则）、`store.js`（预置数据与本地存档）、`app.js`（页面渲染与交互）。无依赖、无服务，直接打开 `index.html` 即可使用。
